# جهّز صورتك — مشاري

أداة عربية مجانية لتجهيز الصور، تعمل محليًا داخل المتصفح بدون رفع الصور إلى خادم.

- حتى 10 صور في المجموعة.
- تغيير المقاس مع الحفاظ على نسبة الأبعاد، وبدون تكبير الصور الصغيرة.
- تصدير WebP وPNG وJPG.
- معاينة الحجم والأبعاد قبل وبعد.
- PNG وWebP يحافظان على الشفافية؛ JPG يستخدم خلفية بيضاء.
- الأداة لا تزيل خلفية الصورة تلقائيًا.
- تنزيل صورة أو مجموعة في ZIP.

النشر: GitHub Pages من فرع main والجذر /. لا توجد حزم أو خطوة بناء.

التواصل: mshary.code@gmail.com — https://www.linkin1.com/mshary.code

الشفرة والأنماط والأصول مضمّنة في index.html لتسهيل النشر. صورة العينة توضيحية مصممة بالذكاء الاصطناعي. الخطوط المستخدمة داخل واجهة الويب هي خطوط النظام، مع عنوان مرسوم بخط ثمانية، دون توزيع ملفات الخط.
